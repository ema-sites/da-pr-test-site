# video-dynamic-media

Custom **video** block. Purpose: Embeds a Dynamic Media video player (viewer iframe or video file), lazy loaded, with optional click-to-play poster..

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row; a cell with the Dynamic Media video URL (viewer page, .../play player, or .mp4), optional poster image and optional caption paragraph.

## Supported variations

No variations.
