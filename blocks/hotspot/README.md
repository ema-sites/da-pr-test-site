# hotspot

Custom **custom** block. Purpose: Interactive image map: circular markers positioned on a background image open Dynamic Media video, 3D viewer, image or text panels..

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: row 1 background image (image or image URL); then one row per hotspot with three cells: content URL or text, left position (x%), top position (y%).

No variations.
