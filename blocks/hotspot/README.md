# hotspot

Custom **hotspot** block. Purpose: full-width image (Iceland map) with positioned hotspot circles that open Dynamic Media video or 3D viewer media in a modal.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: row 1 = background image (picture, image link or plain-text URL); each following row = [media link or list of links (video /play URL or viewer URL), left position % (e.g. 38.5%), top position % (e.g. 39%)].

## Supported variations

No variations.
