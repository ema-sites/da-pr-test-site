# carousel-fullwidth

Custom **carousel** block. Purpose: full-bleed rotating hero of landscape images with prev/next arrows and dot indicators, no text overlay.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: cell 1 = slide image (picture, image link or plain-text image URL, used as authored); cell 2 = optional slide text (heading, description, CTA), left empty for image-only slides.

## Supported variations

No variations.
