# hotspot-video-map

Custom **hotspot** block. Purpose: Full-width image (e.g. a map) with absolutely positioned circular hotspots that open a Dynamic Media video or Scene7 viewer in a modal.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: row 1 = background image (single cell: picture, image link or bare URL); then one row per hotspot: cell 1 = media URL (DM delivery /play URL or Scene7 viewer URL), cell 2 = left position in % (e.g. 38.5%), cell 3 = top position in % (e.g. 39%), optional cell 4 = accessible label.

## Supported variations

No variations.
