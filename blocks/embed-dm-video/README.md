# embed-dm-video

Custom **embed** block. Purpose: Embeds an Adobe Dynamic Media / Scene7 video viewer (e.g. SmartCropVideoViewer.html) in a responsive 16:9 iframe.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: single cell: the viewer URL as a link or bare text (query string configures the viewer and is kept as-is); optional poster image above the URL turns it into click-to-play.

## Supported variations

No variations.
