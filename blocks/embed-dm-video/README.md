# embed-dm-video

Custom **embed** block. Purpose: Dynamic Media (Scene7) video viewer iframe, 16:9.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: single cell = Scene7 viewer URL (e.g. SmartCropVideoViewer.html?asset=...), as a link or plain text; optional poster picture above the link turns it into click-to-play.

## Supported variations

No variations.
