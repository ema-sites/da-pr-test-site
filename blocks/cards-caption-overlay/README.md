# cards-caption-overlay

Custom **cards** block. Purpose: Row of image tiles with a short caption overlaid on a dark gradient at the bottom; no title or CTA.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per tile; cell 1 = image (picture, image link or bare Dynamic Media Open API URL with transformation params, kept as-is); cell 2 = short caption text.

## Supported variations

No variations.
