# carousel-hero

Custom **carousel** block. Purpose: Full-bleed rotating image slideshow at the top of the page, with prev/next arrows and dot indicators.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per slide; cell 1 = slide image (picture, image link or bare Dynamic Media URL, rendered with its query string intact); cell 2 = optional text (heading, description, CTA), may be left empty.

## Supported variations

No variations.
