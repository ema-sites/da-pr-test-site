# cards-tour

Custom **cards** block. Purpose: Grid of tour/product cards: image, two-line title, pill CTA, description.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per card; cell 1 = card image (picture, image link or bare Scene7 templated URL, kept as-is); cell 2 = title paragraph (first paragraph, may contain a line break), a paragraph with a single CTA link, then description.

## Supported variations

No variations.
